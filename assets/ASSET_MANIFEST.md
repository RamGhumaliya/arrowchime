# Asset Manifest

Every file the code references. Claude Code must create **obvious placeholders with these exact paths** (via `tool/gen_placeholder_assets.dart`, rules in `docs/10_DESIGN_SYSTEM.md` §10) so final **human-made** art/audio can be dropped in later with no code changes. Claude Code never generates or downloads realistic images for these paths.

Formats: images WebP (PNG fallback for icons), audio OGG (WAV for placeholders is fine — keep the same base name and switch extension in one constant file `lib/core/assets.dart`).

**Implementation (Phase 2):** `lib/core/assets.dart` is the single source for every path below (`AssetCatalog`) and holds the two extension constants (`AssetFormats.image = 'png'`, `AssetFormats.audio = 'wav'` for the placeholders; change to `webp` / `ogg` when final files land). `dart run tool/gen_placeholder_assets.dart` writes a placeholder at every path (305 files) and never overwrites an existing file without `--force`, so real assets are safe. Pitched note names use `s` for sharp (`Fs5`), never `#`. Flutter does not recurse into asset folders: every directory is listed in `pubspec.yaml` (`AssetCatalog.assetDirectories()`; a test keeps them in sync).

## Levels
